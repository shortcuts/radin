# Ask rule

The one rule for asking the user a question. Each skill and sub-agent prompt that asks names this file.

Ask with your structured question tool. Put at most 3 questions in one call and at most 3 options in each question, recommended option first. When the tool is missing or refuses (Codex Default mode), ask one numbered plain-text question and wait for the answer. A decision with more than 3 options, or more than 3 questions, becomes sequential asks.
